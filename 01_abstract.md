# Abstract

**Title:** Machine Learning-Based Volcanogenic Massive Sulfide (VMS) Prospectivity Mapping in the Bathurst Mining Camp: Integrating Multi-Physics Geophysics and Raw Multi-Element Till Geochemistry

Discovering buried Volcanogenic Massive Sulfide (VMS) deposits requires the integration of heterogeneous, multi-scale geoscience datasets. We present a machine learning pipeline for VMS prospectivity mapping in the historic Bathurst Mining Camp (BMC), New Brunswick, Canada. This approach integrates compiled aeromagnetic, gravity, and radiometric datasets with a newly compiled, spatially unified 17-element till geochemistry dataset containing 2,753 sample locations. 

To prevent high-frequency noise and interpolation slope artifacts, vertical and horizontal geophysical derivatives (First Vertical Derivative, Total Horizontal Gradient, Analytic Signal, and Tilt Derivative) were computed on their native grids prior to reprojection. Geochemical point data was interpolated using Inverse Distance Weighting (IDW) and processed using Centered Log-Ratio (CLR) transformations, Principal Component Analysis (PCA), and Factor Analysis (FA) to minimize compositional bias. A geologically weighted Multi-Element Anomaly Score (MEAS) was computed to capture proximal pathfinder associations. 

Random Forest and XGBoost classifiers were trained on 295 spatial labels (45 VMS deposits and 250 barren drill holes) using Synthetic Minority Over-sampling Technique (SMOTE) for class balancing. To ensure robust performance estimates and mitigate spatial autocorrelation, model performance was evaluated using 5-fold spatial block cross-validation. We assessed classifiers using a multi-dimensional validation suite comprising Receiver Operating Characteristic (ROC), Precision-Recall (PR), and cumulative Success Rate (Prediction-Area) curves. In dataset assembly, 13 raw geochemistry elements were retained after applying a 75% data-completeness threshold. 

The Random Forest model outperformed XGBoost, achieving a spatial cross-validation ROC-AUC of $0.816 \pm 0.178$, an Average Precision of $0.544 \pm 0.272$, and a Success Rate Curve AUC of $0.722$ (compared to $0.684$ for XGBoost). Notably, the integration of raw geochemistry features significantly boosted performance, with raw Lead concentration (`pb_ppm`) emerging as the third most critical feature in the model (3.89% Gini importance), alongside key geophysical indicators such as the magnetic Tilt Derivative. The resulting 100-meter resolution prospectivity map highlights high-priority, spatially coherent exploration targets, demonstrating the efficacy of combining raw multi-element geochemical footprints with multi-physics geophysical derivatives for greenfield mineral exploration.
